# 毕业设计说明书材料

此处是公开脱敏版，姓名、学号、导师字段为空。含身份信息的原件和早期草稿保存在私有仓库 `ityongsheng/m09-private-backup`；公开模板仅清理文档编辑者元数据。接触表由公开 DOCX 重新渲染。

`毕业设计说明书_m09_v1.0.docx` 是按河北工业职业技术大学论文规则草案 v1.0 和学校模板生成的说明书工作稿。正文围绕真实仓库实现编写，已纳入数据清洗、HDFS 实机运行、互信息加权 XGBoost、Spring Boot/SQLite/API 联调和 Windows x64 模型运行器 EXE 证据，并配置了 18 张编号图（含 5 张真实 Web 运行截图）、三线表、双语摘要、目录、参考文献、致谢和附录。

重新生成 DOCX：

```bash
python3 thesis/build_thesis_v1.py
```

规则审查明细见 [`论文规则审查记录.md`](论文规则审查记录.md)，其中记录了正文 16,000、全文计数区 21,756、正式题名超 25 字的批准题名例外，以及本地渲染、Windows 和学校平台验收边界。

提交前需要人工收口的内容：

- 在 `thesis/文献核验台账.json` 中逐条完成 CNKI/VIP 或出版社来源核验；
- 补齐学生、导师签名和提交日期，以及企业指导教师信息（当前保持空白）；
- 在目标 Word 和学校论文平台进行最后一次导入、目录和页面级检查；当前已完成 LibreOffice 本地渲染和本机真实 Web 截图核对；
- Windows 交付范围目前是模型运行器 EXE 烟测，不是全应用离线包。

对应的实验、运行和测试证据位于仓库 `evidence/` 目录。

本地渲染的 39 页页面接触表见 `evidence/thesis/render-contact-sheet.png`；它使用 LibreOffice 逐页转 PDF 后生成，用于检查图、表、中文字体和分页是否实际可见。
