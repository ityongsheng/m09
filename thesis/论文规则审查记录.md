## 需要保留的例外或未验证边界

- 开题报告正式题名为“基于 Hadoop 与 XGBoost 的生鲜仓储损耗预测系统的设计与实现”，去除空格后超过 25 字。依据手册“正式批准题名不静默改写”的处理，当前文档保持开题报告题名，并把题名长度记为项目例外；如指导教师要求改题，应同步修改开题报告、封面、摘要和代码交付说明。
- 当前已完成 LibreOffice 本地 PDF/页面图渲染和本机浏览器截图核对；尚未在目标 Windows Word 和学校论文平台完成最终导入验收，因此不把本地渲染称为学校格式通过。
- Windows x64 已验证 PyInstaller 模型运行器 EXE；Java、SQLite、静态资源和浏览器组成的全应用 Windows 离线包仍为“未验证”。
- 数据集没有时间戳，论文使用“传感器记录分类”解释实验，不将固定切分结果写成时间序列或现场损耗率。
