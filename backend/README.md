# m09 backend

## Local run

```bash
mkdir -p runtime
mvn -f backend/pom.xml test
M09_DB_PATH=./runtime/m09.sqlite \
M09_MODEL_COMMAND=$PWD/scripts/run_model.sh \
M09_PYTHON=$PWD/.venv/bin/python \
M09_MODEL_PATH=$PWD/artifacts/model/weighted_xgboost.joblib \
mvn -f backend/pom.xml spring-boot:run
```

The `/api/predict` endpoint intentionally returns `503 MODEL_UNAVAILABLE` until `M09_MODEL_COMMAND` points to the model runner. The command receives one JSON request on stdin and must return one JSON object matching `ModelPrediction` on stdout; no fake prediction is generated by the backend. The Windows package will replace the development shell wrapper with a bundled x64 model-runner executable.
